# Канон-мадригал Ogni diletto

**Type:** work
**Status:** active

## Facts

- **Название:** Канон-мадригал Ogni diletto
- **Автор:** Магистр Пьеро
- **Жанр:** мадригал (Треченто)
- **Описание:** Один из немногих сохранившихся мадригалов флорентийского Маэстро (Магистра) Пьеро — одного из старейших мастеров итальянского Треченто (первая половина XIV века), чья музыка дошла в Лондонской рукописи (Британская библиотека, Add. 29987). «Ogni diletto» написан как канон-мадригал для двух голосов с изысканной подвижностью верхнего голоса.
