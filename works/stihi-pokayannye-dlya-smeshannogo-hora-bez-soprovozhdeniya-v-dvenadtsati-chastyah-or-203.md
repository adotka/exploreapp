# «Стихи покаянные» для смешанного хора без сопровождения в двенадцати частях, ор. 203

**Type:** work
**Status:** active

## Facts

- **Название:** «Стихи покаянные» для смешанного хора без сопровождения в двенадцати частях, ор. 203
- **Автор:** Альфред Шнитке
- **Описание:** Крупный хоровой цикл Альфреда Шнитке, написанный в 1988 году к юбилею 1000-летия Крещения Руси, основан на текстах древнерусских покаянных стихов XVI–XVII веков. Произведение для смешанного хора a cappella отличается глубокой духовной сосредоточенностью, суровой аскетичностью звучания и обращением к древнерусской певческой традиции, преломлённой через современный музыкальный язык композитора. Считается одним из вершинных достижений позднего творчества Шнитке в области хоровой музыки.
