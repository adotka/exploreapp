# Три духовных хора для смешанных голосов, op. deest (Богородице Дево, радуйся; Господи, Господи Иисусе; Отче наш)

**Type:** work
**Status:** active

## Facts

- **Название:** Три духовных хора для смешанных голосов, op. deest (Богородице Дево, радуйся; Господи, Господи Иисусе; Отче наш)
- **Автор:** Альфред Шнитке
- **Описание:** Небольшой цикл из трёх духовных хоров a cappella на канонические православные тексты, написанный Альфредом Шнитке для смешанного хора. Произведение выдержано в аскетичной, сдержанно-возвышенной манере, сочетающей отголоски древнерусской певческой традиции с современным гармоническим языком композитора. Предназначено для концертного исполнения хоровыми коллективами, а не для богослужебного употребления.
